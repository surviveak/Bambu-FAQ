# Bambu Lab H2C FAQ

A community-maintained FAQ focused on the **Bambu Lab H2C**, Vortek, AMS/FTS, Bambu Studio, filament profiles, materials, maintenance, and print optimization.

> **Status:** Initial FAQ assembled from hands-on questions and research. Bambu Studio, firmware, and accessory behavior can change; version-sensitive entries should be rechecked against current Bambu documentation.

## Conventions

Original question IDs (Q001, Q002, etc.) are retained as stable references even though questions are now grouped by topic.

## Important note

Settings in this FAQ are starting points, not universal guarantees. Filament formulation, moisture, nozzle diameter, hotend type, firmware, Bambu Studio version, model geometry, and ambient conditions can all change the result.

## Sources

Where manufacturer-specific settings are quoted, prefer the manufacturer's current documentation and downloadable presets. Useful starting points include the [Bambu Lab H2C product/documentation ecosystem](https://bambulab.com/) and [Overture preset documentation](https://wiki.overture3d.com/en/Basics/OverturePreset).
